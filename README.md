# NextUI WASM-4 Pak

A [WASM-4](https://wasm4.org/) [Libretro](https://www.libretro.com/) core for use with [NextUI](https://nextui.loveretro.games/) to play WASM-4 games.

## Installation

1. Download the WASM.pakz file from the [latest release](https://github.com/amayer5125/nextui-wasm-4-pak/releases) on GitHub.
1. Extract the zip file to the root of your SD card. You should see a new WASM.pak directory under `/Emus/<platform>` after extracting.
1. Create the `/Roms/WASM-4 (WASM)` directory on your SD card for your games.

You can download games for free from the [WASM-4 website](https://wasm4.org/play). Place the .wasm files in the `/Roms/WASM-4 (WASM)` directory.

## Debug Logs

If you are having trouble launching games you can look for clues in the debug logs at `/.userdata/<platform>/logs/WASM.txt`.
